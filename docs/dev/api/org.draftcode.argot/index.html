Top-level declarations

cli

fun <T> cli(block: () -> T): T

Runs block and turns Argot's outcomes into the usual command-line behaviour:

  • success returns the parsed value;

  • --help and --version print to stdout and exit 0;

  • invalid input prints the usage line and error: … to stderr and exits 2.

fun main(argv: Array<String>) {
    val args = cli { parseServeArgs(argv) }   // generated parser, or ServerArgs().parse(argv)
    runServer(args)
}

fun <T> T.parse(argv: Array<String>): T

Parses argv into this instance and returns it, without printing or exiting.

ThrowsHelpRequested

if --help or -h is present.

ThrowsVersionRequested

if --version is present and a version is configured.

ThrowsArgotParseException
