ArgotTyped command-line parsing for Kotlin

Declare your parameters once, get validated values at startup. No runtime reflection, no third-party dependencies.

API reference
GitHub

Two styles, one engine

Plain Kotlin delegates, or annotate a data class and let a KSP processor write the parser. Behaviour and help output are identical either way.

Nothing at runtime

argot-core and argot-annotations depend only on the Kotlin standard library. KSP and KotlinPoet never reach your runtime classpath.

Errors at compile time

Duplicate names, misplaced positionals and unsupported types are reported while you build, not when a user runs your program.
