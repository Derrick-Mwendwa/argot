# Learn Argot

This section is organised the way [Diátaxis](https://diataxis.fr) suggests, because the four things
documentation does are genuinely different jobs:

| | For when you want to |
|---|---|
| **[Tutorial](./tutorial/your-first-cli)** | learn Argot by building something, start to finish |
| **[How-to guides](./how-to/)** | accomplish one specific task you already have in mind |
| **[Explanation](./explanation/)** | understand why Argot works the way it does |
| **[Reference](../api/)** | look up an exact signature or default |

New to Argot? Start with [your first CLI](./tutorial/your-first-cli). It takes about ten minutes and
ends with a working program.

::: tip Every code block here is compiled
The examples on this site are regions of real Kotlin files that live in the repository and are
compiled — and run — on every change, and again against each published release before these pages
are deployed. If a snippet appears here, it worked.
:::
